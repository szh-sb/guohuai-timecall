# 国槐计划｜时空来电 3.8：十位历史人物专属音色

这是面向初中生的历史人物 AI 情景互动网站。保留了十位国风肖像、快速猜谜、朝代先后判断、一键揭晓、人物通话和 DeepSeek 文本对话。

## 本次升级
- 十个人物各有独立的声音风格、语速、音高及试听台词，涵盖李白的清朗豪放、杜甫的低沉深情、李清照的清雅婉约等。
- 通话界面的 **🎚️ 人物音色** 可列出当前 Edge/浏览器的中文声音，优先匹配名称中带 Natural/Neural/Online 的自然音色，支持手动选声线、调语速/音高、试听、重置。
- 朗读开始/结束驱动口型、声波与动作；如果浏览器有朗读边界事件，则用于近似定位嘴型。
- AI 回复提示加入人物语言风格，尽量使用便于口头表达的短句。
- 依旧可以在网页临时填写 DeepSeek API Key，但直接请求可能因 CORS 被拦截，且明文浏览器访问存在密钥暴露风险。

## 访问
网站（如 GitHub Pages 已成功启用）：https://szh-sb.github.io/guohuai-timecall/

打开后：教师演示 → 选择杜甫/李清照/李白 → 人物音色 → 试听并更换音色。旧版本缓存可用 Ctrl+Shift+R 刷新。

## 技术边界
- 没有历史人物真实录音，配音为现代语音合成演绎，不能宣称是古人原声。
- 自然声线的种类由当前设备/浏览器决定。若仅能使用传统系统语音，微调音高、语速仍不能保证听起来像真人；进一步改善需要独立 TTS 服务。
- 本版保留李白、苏轼的三帧嘴型；其他人物主要为静态画像和整体动作，并非真实逐音素口型。
- 本次完成网页端按钮操作和模拟音色匹配测试；没有测试用户电脑上实际 TTS 输出的自然度、GitHub Pages 发布时间或 DeepSeek 真实联网。
