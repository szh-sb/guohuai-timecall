# 国槐计划｜时空来电 3.7

一个适合初中课堂使用的历史人物互动网页，可在 GitHub Pages 上打开，无需安装 Python。

## 3.7 本次修复

- 修复除李白、苏轼以外的八位人物仍显示旧 SVG 卡通头像的问题。**十位人物均使用内嵌半写实国风肖像**，不依赖额外图片路径；李白、苏轼保留已有三帧口型，其余八位为静态肖像与轻微整体动作。
- 修复猜谜问题“**他是不是清朝以前的人？**”被错误判断为“不是”。新增朝代时间关系解析，支持“以前、之后、在某朝代”等常见问法，准确的年代问题优先本地即时判断；未能判断的复杂线索可使用 AI。
- 保留十位人物的猜谜、一键揭晓、教师演示、角色对话、语音朗读、临时填写 DeepSeek 密钥。
- 素材均为教学使用的艺术化形象，**不代表历史人物真实面貌**。

## 关于 DeepSeek

网页当前使用浏览器临时填写的 API Key，**不会将密钥写入 GitHub 源码**。但浏览器直连存在密钥泄露风险，且可能受到 DeepSeek 的 CORS 限制；这并非单凭有密钥就能保证连接。需稳定教学时，建议改为受保护的服务端代理。

## 自测建议

1. 进入“教师演示”选杜甫，应看到国风写实肖像而不是卡通头像。
2. 新开猜谜，输入“是不是清朝以前”，随机的十位候选人物都应答“是”。
3. 选杜甫，输入“他生活在唐朝吗？”应答“是”。
4. 猜中或点击“直接揭晓”，应进入对应人物的对话。
